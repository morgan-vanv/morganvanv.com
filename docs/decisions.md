# Decisions

One line per decision: what was decided and why. Newest at the bottom.

- **2025-07-27** Migrated the site to the Angular CLI project structure.
- **2026-05-25** Pivoted from a classic portfolio to a personal site inspired by the IndieWeb, Web Revival, and neocities. Professional info stays, but isn't the focus.
- **2026-05-25** Added arrow-key navigation between pages with directional slide transitions. Route order is the navigation order.
- **2026-05-25** Interests pull live data (stats.fm, Wise Old Man, later RuneProfile) instead of hand-maintained lists, so the site stays current on its own.
- **2026-05-26** Replaced the WOM achievements feed with RuneProfile's activities endpoint.
- **2026-05-28** All main routes are lazy-loaded with OnPush change detection; shared constants extracted (e.g. `SOCIAL_LINKS`).
- **2026-06-05** Anonymous "Ask Morgan" form posts to a DigitalOcean serverless function with a honeypot field — the site itself stays static.
- **2026-06-07** Community Photo Wall: visitors email photos, Morgan adds them as compressed webp. 12 fixed polaroid slots, empty ones invite submissions.
- **2026-06-07** Interests page uses a shared keyboard-navigable vertical nav component.
- *(undated)* `withViewTransitions()` is intentionally not used; it conflicts with `@routeAnimations`.
- **2026-10-24** Set up the Claude project workflow: briefing docs in the Claude project, `CLAUDE.md` imports `.github/copilot-instructions.md` so conventions live in one file.
- **2026-10-25** Restructured `docs/ideas-later.md` into a categorized backlog (tech debt, SEO, features, patterns) with effort tags, seeded from a full repo audit.
- **2026-10-25** Fonts are bundled from `@fontsource` (latin subsets); no Google Fonts. The production build must never need the network.
- **2026-10-25** Dropped Angular Material and icon fonts for an inline-SVG `app-icon` component; kept `@angular/cdk` for the focus trap.
- **2026-10-25** Route transitions moved to the View Transitions API (`withViewTransitions`), replacing the deprecated `@angular/animations`; this supersedes the earlier note about avoiding `withViewTransitions()`. Only `<main>` slides; the background stays.
- **2026-10-25** Zoneless change detection, signal inputs and `host` metadata everywhere.
- **2026-10-25** Navbar links derive from `MAIN_ROUTES`; arrow-key scrolling targets are registered with `[appScrollRegion]` instead of hardcoded selectors.
- **2026-10-25** All handles/URLs live in `SITE_CONFIG`; API reads go through `ApiCacheService` (sessionStorage, 10 min).
- **2026-10-25** Tests run on Vitest (happy-dom), not Karma. `vitest` pinned to `~4.0` until npm 10's optional-peer crash is fixed.
- **2026-10-25** Every route is prerendered (`@angular/ssr`, `outputMode: static`) and hydrated; no runtime server. Prerendered pages never embed live API data.
- **2026-10-25** SEO lives in `SeoTitleStrategy` + `index.html`; canonical URLs and the sitemap use trailing slashes to match GitHub Pages' directory redirects.
- **2026-10-25** Lighthouse CI runs on PRs; accessibility (axe-core) and SEO scores below 0.95 fail the check, performance/best-practices only warn.
- **2026-10-25** Promoted three "alive" features (last listened, `/now`, Tonight's sky) to `docs/roadmap.md` with decisions: `/now` is a main route after Home; the sky is stars + Moon + planets via lazy-loaded `astronomy-engine`, Cincinnati by default with an opt-in "my sky" toggle; last-listened appears on the greeting and the Music card.
- **2026-10-25** "Last listened" is a root `RecentStreamService` that polls stats.fm every 90 s while the tab is visible (and on becoming visible), tries `streams/current` first so "right now" is true, then falls back to `streams/recent`. Shown as a rotating greeting subtitle and a card atop Music. `ApiCacheService.get(url, 0)` bypasses the cache.
- **2026-10-25** Music tab layout: now-playing is a full-width centred band; top lists are framed panels with rank numbers (top three in gold), "plays" and whole-unit playtime. Expanded Interests cards (shared) put Esc in the title row and use a smaller title; projected description content is styled from the item's own stylesheet (`.expanded [description]`; the `is-expanded` host class was dropped in #87). No playback progress bar: the site shows only what stats.fm reports at fetch time.
- **2026-10-25** `/now` is a main route after Home. Its "Site" row comes from `scripts/write-build-info.mjs` (the `prebuild` hook), which writes a gitignored `src/build-info.prod.ts` swapped in by `fileReplacements`; the committed `src/build-info.ts` holds dev placeholders and the type lives in `build-info.model.ts` (a replaced file can't import from itself). The generated file has no imports, so a stale copy left by a branch switch still compiles anywhere. Dates show the commit's own calendar day. GitHub merge commits are shown by PR title.
- **2026-10-25** OSRS section refresh (PR #81): character band, framed Skills / Progress / Pets panels, Achievements · Drops row, full-width named Boss Kills grid sorted by kills. Panel styling lives in shared mixins (`panel`, `panel-heading`, `progress-bar`) used by Music too.
- **2026-10-25** Bands and notes use the same neutral surface as panels (`surface` mixin: dark fill, faint border); the gold gradient was dropped as clashing. Gold stays for labels, ranks and the "playing now" border.
- **2026-10-25** Projects start as data (`shared/constants/projects.const.ts`) rendered by a reusable `app-project-card`, shown under "Building" on /now. "Updated N ago" comes live from the public GitHub API (cached 30 min). The future Projects page lists the same entries.
- **2026-10-26** Tonight's sky: the real sky (stars ≤ mag 4.5, 30 constellation figures, Moon with phase, naked-eye planets, Sun) drawn on a canvas over `background.webp` with the painted landscape in front (originally as pixel art; see below). Stars and the Sun use our own tested math; the Moon and planets come from `astronomy-engine`, lazy-loaded. Cincinnati unless the visitor clicks "show my sky" in the sky menu; their location is rounded to 0.1° and kept in `localStorage`, so it's only ever requested on that click. Redrawn once a minute while visible, never on a timer under reduced motion. The painted sky is the first paint and the fallback. Page cards darken by `--daylight` so text stays readable under a noon sky.
- **2026-10-26** The sky defaults to **darkness** (real star positions, Sun ignored). A top-right ☾ menu offers real time, sunrise, sunset and day, remembered per visitor. Sunrise and sunset are staged: the Sun sits in the valley between the painted mountains, not where it really is.
- **2026-10-26** Design pillar: **night is home.** Dark is the default and the design target; brighter looks are opt-in settings, never the landing state.
- **2026-10-26** Design pillar: **cultivate an atmosphere.** Flavor and small easter eggs are worth building, as long as they stay quiet, discoverable and accessible.
- **2026-10-26** Sky hover labels: hovering (or tapping) open sky names the star, planet, Moon or constellation under the pointer and brightens its figure. Only over open sky, never over text, controls, cards or the landscape; the canvas stays `aria-hidden` and the menu's "up right now" list is the text equivalent.
- **2026-10-26** The background stays Morgan's painting, and the sky is drawn to suit it: smooth gradient, soft stars, thin antialiased lines, gentle glow, at device resolution. (A pixel-art version of the sky and a from-scratch pixel-art landscape were tried and dropped: they lost the painting's warmth and softness.) `scripts/build-landscape.py` cuts the sky out of the lossless original (`art/painting.png`) with a soft matte and bakes four relit looks (darkness = the painting's own colours, sunrise with morning fog, sunset, day); real time blends them by the Sun. A light stays on in the farmhouse after dark; fireflies drift at dusk. `background.webp` is the original painting, first paint and fallback.
- **2026-10-26** Changing the sky's light eases instead of cutting: the new light is drawn once on a second pair of canvases and crossfaded in over 2.4 s while the Sun (its own element) travels, rises out of the valley or sets behind the hills. Recompositing the whole canvas every frame was tried first and dropped: too heavy at 2×. Instant under reduced motion. A small flickering campfire sits beside the farmhouse after dark, and the window light breathes a little; both CSS.
- **2026-10-26** Upgraded to Angular 22 (and TypeScript 6.0, which it requires) with `ng update` and its migrations. Kept Angular's new defaults rather than the migrations' opt-outs where they change nothing here: Fetch-backed `HttpClient` (dropped `withFetch()`), incremental hydration (no `@defer` blocks), no extended-diagnostic suppressions (none fire). Components stay explicitly `OnPush`. Before/after screenshots of every route, light, transition and hover label matched. TypeScript 7 waits for Angular; the Vitest `~4.0` pin stays (npm 10 still crashes on 4.1).
- **2026-10-26** Site-wide face-lift (approved from the canvas mockups): the Music/OSRS habits everywhere. Compact page headers, an anchor band, panels in grids that use the width, a fixed type scale (no more type scaling with window height). The page card is 90% of the window up to 1600px (ultrawide keeps the painting) and 0.5rem from the edges on tablets/phones. Named breakpoints: phone 600, mobile 1000, short 500 (height), wide 1600.
- **2026-10-26** Phone navigation is a pager (greeting, ‹ prev, `[ current ]` opening the page list, next ›) rather than a swipeable strip or a bottom bar: it matches the arrow-key and slide navigation and keeps one row. The ☾ sits in its last slot on small screens.
- **2026-10-26** Interests is a grid of tiles with live previews (last listened; OSRS combat/total/99s/EHP). Music shows one top list at a time on tablets/phones, chosen with Songs/Albums/Artists toggle buttons (not ARIA tabs, so ← → stay page navigation). The previews sit centred in the tile under its header. The OSRS band gives the 3D character most of its height and adds a 99s progress row with Wise Old Man's hours-to-max.
- **2026-10-26** Lighthouse runs as a phone as well as desktop, on all eight routes; the 0.95 accessibility/SEO bar applies to both.
- **2026-10-26** The greeting's way in is a glass pill link in the navbar's idiom (`[ come on in › ]`, gold brackets on hover/focus) with an `or press →` keycap hint hidden on touch screens, replacing the big "Click / Arrow Keys" button.
- **2026-10-26** `archived-old-website` (the original 2019 site) is permanent: never deleted, excluded from branch cleanups, backed up to Morgan's Google Drive as a zip and a git bundle.
- **2026-10-26** Design pillar: nimble, not enterprise. Checks and best practice yes, administrative overhead no: a check earns its place if it runs itself and only speaks up when something is actually wrong.
- **2026-10-26** Lighthouse CI tuned in that spirit: one config (`lighthouserc.cjs`) that reads its pages from the sitemap, three runs per page, loose page-weight/JS/image/CLS ceilings that fail the PR (they catch accidents; raise them when growth is deliberate), and a score table on the check's Summary page. No report archive, no extra services.
- **2026-10-26** Badges are 88×31 buttons drawn at 1.5× (132×46): the shape is the nostalgia, the size keeps the text readable and clears the 44px tap target, and the accessible name carries the full text. They live in a strip under Lately on `/now`. First one: the site's own Lighthouse scores (homepage, phone), measured at deploy and linking to a live PageSpeed Insights run; option A (classic bevelled button) chosen over a glass pill.
- **2026-10-26** The badge strip grows into its own full-width "Buttons" panel at the bottom of `/now`, in two labelled rows (tonight / this site), rather than under Lately or in a site-wide footer: only one page pays for the badges' requests, and the "this site" row can move to a colophon later in one line. Every badge renders through one shell (`app-badge`), so the 88×31 look lives in one place.
- **2026-10-26** `UNDER_CONSTRUCTION` (`src/shared/constants/under-construction.const.ts`) is the one list of unfinished spots: the pages show their gif or banner only while listed, and the Under construction badge counts it, so finishing something is one deletion.
- **2026-10-26** The site's own 88×31 is a `.gif` (`public/88x31.gif`, drawn by `scripts/build-88x31.py`), the one deliberate exception to webp besides `og-image.jpg`: other people paste it into old-web pages where gif is the convention. Pressing it on `/now` opens the HTML to copy rather than leaving the page.
- **2026-10-26** The tonight row: Moon, Up tonight, Weather and Vinyl Collection as separate buttons (Morgan's call over one merged "Tonight" button). Moon and Up tonight reuse the sky's astronomy-engine numbers and open the ☾ menu, which now lives in `SkyService` so other parts of the page can open it. Weather is Open-Meteo (free, no key) for Cincinnati, cached 30 minutes, linking to the National Weather Service; Vinyl Collection is Discogs' public collection, cached 6 hours. Both hide on any error, so a private collection or an outage just means one fewer button.
- **2026-10-26** Build health on `/now` is one Build button (commit number, an LED per check, tests and coverage, days since a failed deploy in the popover) rather than four, and as an 88×31 rather than README-style shields, so the strip keeps one visual language. Everything is looked up once at deploy and written to `site-status.json`, the same pattern as `lighthouse.json`: no API calls or rate limits for visitors, no secrets beyond the job's own read-only token, and a failure just hides the button. Page weight comes from the deploy's existing Lighthouse run.
- **2026-10-26** Badge strip trimmed after a day live (Morgan): tonight is Cincinnati weather, Moon, Up tonight; this site is the site's own 88×31, Made with Angular, No cookies, Page weight, Lighthouse, Build. Photo Wall, Vinyl Collection and Under construction are shelved: hobby/interest tracking and visitor interaction don't fit cleanly as 88×31s and deserve their own treatment, revisited later (`docs/ideas-later.md`). `UNDER_CONSTRUCTION` stays as the one list the pages read.
- **2026-10-26** CI/CD tune-up in the nimble spirit (Morgan's picks from an audit): one ruleset instead of two overlapping protections, PR required but no approvals (the solo maintainer was bypassing every merge), squash-only merges, secret scanning and push protection on. CI is one workflow that builds once (Lint, Test, Build, then Lighthouse and Layout on that build), and all five are required. Node 24 LTS from `.nvmrc`, whose npm 11 lifted the Vitest pin. The house conventions became lint rules. Morgan's layout checker idea is now `scripts/check-layout.mjs` (no sideways scroll, one h1, 44px targets, ☾ clear of the pager, across the size matrix). Dependabot's Actions updates merge themselves; npm updates stay manual because master deploys. Deliberately not added: a coverage floor (the Build badge shows coverage), SHA-pinned actions, CODEOWNERS, PR templates, signed commits, pre-commit hooks, stylelint, staging.
